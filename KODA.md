**java-interview** — это интерактивный справочник вопросов и ответов для подготовки к собеседованию на позицию Java-разработчика. Проект содержит обширную базу вопросов, охватывающих ключевые темы: ООП, JVM, Java Core, коллекции, многопоточность, Spring, JDBC, ORM, базы данных, сети, инструменты и многое другое.

Проект состоит из трёх основных частей:

1. **База знаний** — набор Markdown-файлов (`001-oop.md` … `064-javascript.md`) с вопросами и ответами, отформатированными заголовками `#` (название статьи) и `##` (вопрос).
2. **Интеллект-карта (Mindmap)** — интерактивная визуализация структуры вопросов, построенная на библиотеке GoJS. Расположена в каталоге `mindmap/`.
3. **Опрос (Quiz)** — веб-приложение на Vue.js + Bootstrap для прохождения тестирования по вопросам. Расположена в каталоге `quiz/`.

Основная логика обработки (парсинг Markdown, генерация структуры, обновление оглавления README.md) реализована на Node.js.

## Сборка и запуск

### Установка зависимостей

```bash
npm install
```

### Основные команды (корневой каталог)

| Команда | Описание |
|---|---|
| `npm start` | Запуск основного скрипта: обработка всех `.md`-файлов, обновление оглавления в `README.md`, генерация `lib/questions.js` |
| `npm test` | Запуск тестов через Jest (`test/`) |
| `npm run coverage` | Запуск тестов со сбором покрытия |
| `npm run lint` | Проверка и автоисправление JS/TS-кода через ESLint |
| `npm run mdlint` | Проверка и автоисправление Markdown-файлов через markdownlint |

## Структура проекта

```
├── index.js              ← Главный скрипт обработки
├── lib/                  ← Библиотеки
│   ├── fs.js             ← Обёртка над fs (чтение/запись .md)
│   ├── logger.js         ← Логгер с цветным выводом
│   ├── parser.js         ← Парсер Markdown-файлов (заголовки, вопросы)
│   ├── transformer.js    ← Трансформация: обновление TOC, генерация questions.js
│   ├── mindmap.js        ← Генерация структуры для интеллект-карты
│   ├── speller.js        ← Проверка орфографии (yaspeller)
│   └── questions.js      ← Сгенерированная база всех вопросов (JSON)
├── test/                 ← Тесты Jest
├── mindmap/              ← Веб-приложение: интерактивная карта (GoJS + Webpack)
├── quiz/                 ← Веб-приложение: опрос (Vue.js + Bootstrap + Webpack)
├── 001-oop.md … 064-javascript.md  ← Markdown-файлы с вопросами и ответами
└── README.md             ← Оглавление (генерируется автоматически)
```

## Правила разработки

### Формат Markdown-файлов

- Первая строка: `# Название статьи` (заголовок 1-го уровня).
- Последующие вопросы: `## Вопрос` (заголовок 2-го уровня).
- Текст ответа следует сразу после заголовка вопроса.
- В теле файла есть оглавление (список `+ [Название](#якорь)`), которое автоматически обновляется при запуске `npm start`.

### Добавление нового раздела

1. Создайте файл `NNN-название.md` в корневом каталоге.
2. Используйте формат `# Название` и `## Вопрос`.
3. Запустите `npm start` — оглавление `README.md` и `lib/questions.js` обновятся автоматически.

### Стиль кодирования

- ESLint-конфигурация находится в `.eslintrc.js`.
- Проверка орфографии — через `yaspeller` с конфигом `.yaspellerrc`.
- Markdown-линтинг — через `markdownlint-cli` с конфигом `.markdownlintrc`.

### Тестирование

- Фреймворк: **Jest**.
- Тесты расположены в `test/` (`test-parser.js`, `test-question.js`, `test-transformer.js`, `test-speller.js`, `test-mindmap.js`, `test-logger.js`).
- Запуск: `npm test`.
